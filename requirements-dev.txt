# What the TEST SUITE needs, and nothing else. CI installs exactly this
# (.github/workflows/tests.yml). The app itself never reads this file; to run
# WITNESS, install requirements.txt.
#
#     python -m pip install -r requirements-dev.txt
#     python -m pytest tests/ -q
#
# Deliberately not `-r requirements.txt`. That pulls easyocr + torch (gigabytes,
# and no test needs a GPU) and edge-tts, which would let a test reach Microsoft's
# TTS service over the network. Found by running the suite in an empty venv and
# adding packages until it passed; Pillow went in although nothing failed
# without it, because test_loot_goblin.py silently returns early when Pillow is
# missing, which would pass while testing nothing.
#
# Lower bounds match requirements.txt, so CI tests the same versions a fresh
# install gets.
